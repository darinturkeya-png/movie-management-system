# Movie Management System

## Description
A Java console application for managing movie records. The system retrieves movie data from the TVMaze API, stores it in a text file, and allows users to manage and analyze the data through an interactive menu.

## Features

- Fetch movie data from TVMaze API
- Store movie information in a local file
- List all movies
- Filter movies by genre
- Filter movies by release year
- Update movie information
- Delete movie records
- View statistics about stored movies
- Error logging

## Technologies Used

- Java
- File I/O
- HTTPURLConnection
- ArrayList
- Exception Handling

## Stored Data

Each movie record contains:

- Title
- Release Year
- Rating
- Genre
- Runtime
- Language

## Menu Options

1. Fetch Data from API
2. List Movies
3. Update Movie
4. Delete Movie
5. Statistics
0. Exit

## API Used

TVMaze API

https://api.tvmaze.com/shows?page=0

## Statistics Available

- Total number of records
- Average rating
- Highest rated movie
- Lowest rated movie
- Total runtime
